# Bahasa Melayu SPM 표지 애니메이션

압축을 풀고 index.html을 브라우저로 열면 자동 재생됩니다. 인터넷 연결이나 설치가 필요하지 않습니다. HTML, CSS, JS와 assets 폴더를 함께 유지하세요.

제공된 이미지 7개를 사용하고 layout.jpg를 최종 배치 기준으로 삼았습니다. 학생·책 사진과 하단 기관명은 배경 이미지에 포함되어 배경과 함께 등장합니다.

전체 재생 시간은 3.35초입니다.
- 0–0.7초: 배경 디졸브
- 0.35–1.05초 / 0.55–1.25초: 두 로고가 위에서 순서대로 등장
- 0.7–1.5초: LONJAKAN PRESTASI 가로 제목이 왼쪽에서 등장
- 1.2–2.05초: BAHASA MELAYU가 왼쪽에서 등장
- 1.8–2.6초: SPM이 왼쪽에서 등장
- 2.35–3.1초: 집필진 상자가 아래에서 등장
- 이후 완성 화면 유지. 우측 하단 ↻ 버튼으로 다시 재생

1500 × 1000 비율을 유지하며 화면에 맞게 축소됩니다. 동작 줄이기 설정에서는 완성 화면을 바로 표시합니다.
배치는 style.css, 시간과 이동 거리는 animation.js에서 수정할 수 있습니다.
